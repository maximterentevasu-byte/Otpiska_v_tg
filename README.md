# TG Custdev Bot для Pick me

Бот отслеживает пользователей, которые вышли из Telegram-группы, записывает их в Google Sheets, генерирует персональную ссылку на опрос и проводит анкетирование внутри Telegram.

## Что делает

1. Бот добавляется админом в Telegram-группы.
2. Когда пользователь выходит из группы, бот записывает его в лист `Отписавшиеся`.
3. В листе появляется:
   - дата отписки;
   - кликабельная ссылка на пользователя;
   - персональная ссылка на интервью;
   - готовое сообщение для админа.
4. Админ вручную пишет пользователю и отправляет готовый текст.
5. Пользователь открывает ссылку вида:

```text
https://t.me/YOUR_BOT_USERNAME?start=interview_USER_ID
```

6. Бот запускает опрос, задаёт 11 вопросов и после этого просит телефон бонусной карты Pick me.
7. Ответы записываются в лист `Ответы` и дополнительно в JSON на листе `Отписавшиеся`.

## Листы Google Sheets

Бот сам создаёт листы, если их нет:

### `Отписавшиеся`

```text
ID пользователя | Юзернейм | Имя | Ссылка на пользователя | ID группы | Название группы | Дата отписки | Статус | Ссылка на интервью | Готовое сообщение для админа | Ответы JSON | Дата завершения опроса | Телефон бонусной карты
```

### `Ответы`

```text
ID пользователя | Юзернейм | Имя | Зачем изначально подписался | Ожидания и реальность | Момент решения отписаться | Что не устраивало | Где получает информацию сейчас | Что удержало бы | Условия возврата | Чем занимается | Что было полезно | Что изменить в группе | Возраст | Телефон бонусной карты | Дата завершения опроса
```

## Переменные окружения Railway

```text
TELEGRAM_BOT_TOKEN=
BOT_USERNAME=
PUBLIC_URL=
WEBHOOK_SECRET=
PORT=3000
GOOGLE_SHEET_ID=
GOOGLE_SERVICE_ACCOUNT_EMAIL=
GOOGLE_PRIVATE_KEY=
ALLOWED_GROUP_IDS=
```

`BOT_USERNAME` указывай без `@`.

`PUBLIC_URL` — домен Railway без `/` в конце, например:

```text
https://otpiskavtg-production.up.railway.app
```

`GOOGLE_PRIVATE_KEY` лучше вставлять одной строкой с `\n`, как в JSON-файле:

```text
-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----\n
```

`ALLOWED_GROUP_IDS` можно оставить пустым. Тогда бот будет учитывать все группы, где он админ.

Для ограничения двумя группами:

```text
ALLOWED_GROUP_IDS=-1001111111111,-1002222222222
```

## Проверка

1. Залей проект в GitHub.
2. Дождись деплоя Railway.
3. В логах должно быть:

```text
Webhook set: https://.../telegram/...
```

4. Открой:

```text
https://твой-домен.railway.app/health
```

Должно вернуть:

```json
{"ok":true}
```

5. Выйди тестовым пользователем из группы.
6. Проверь лист `Отписавшиеся`.
7. Открой ссылку из колонки `Ссылка на интервью`.
8. Пройди опрос.
9. Проверь лист `Ответы`.

## Ограничения Telegram

- Бот не может первым написать пользователю, пока пользователь сам не открыл бота.
- Deep link открывает бота с параметром `start`. В Telegram пользователь всё равно может увидеть кнопку Start, но после нажатия опрос стартует автоматически.
- Чтобы бот видел выходы пользователей, он должен быть админом группы и получать `chat_member` updates.
